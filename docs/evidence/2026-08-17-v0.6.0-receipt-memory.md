## Remaining boundary

The local state file is not application-encrypted and relies on OS account/disk protection in addition to its private permissions. It can still reveal habits through purposes/subtotals. Default-off enablement, retention, bounded search, exact per-record deletion, and full purge mitigate but do not remove this risk. Any future hosted or multi-user implementation requires encryption and tenant isolation.
